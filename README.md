# Сортировщик ФИО

Приложение: вставляете текст/код из буфера обмена → цифры удаляются →
люди сортируются по алфавиту в таблицу «Фамилия Имя» с комментарием
(группа) и подсчётом уникальных людей.

## Варианты

| Файл | Описание |
|---|---|
| `sort_table.html` | Веб-приложение: открыть в браузере, кнопка «Вставить из буфера», таблица, статистика по группам, экспорт CSV |
| `sorter.py` | Desktop GUI (tkinter) + CLI-режим |

## Запуск Python

```bash
python3 sorter.py                 # графическое окно (кнопка «Из буфера обмена»)
python3 sorter.py --cli           # результат в консоли из буфера обмена
python3 sorter.py --file f.txt    # разобрать файл
cat f.txt | python3 sorter.py     # из stdin
```

## Поддерживаемые форматы строк

```
1. Иванов Иван — группа А
2. Петров Пётр | Б
3. Сидорова Анна (группа В)
4. ivanov ivan - гр. А
5. 123987 Обручев Сергей 45 — А
6. Яковлева Мария, группа Б-3
```

Дубликаты (с учётом регистра и ё/е) объединяются с меткой ×N;
выводится общее число записей, число уникальных людей и размер каждой группы.
